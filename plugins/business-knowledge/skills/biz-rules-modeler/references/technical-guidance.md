# Guía técnica — biz-rules-modeler

Objetivo: Extraer reglas de negocio, estados, validaciones, permisos y excepciones con trazabilidad a fuentes y términos del glosario. Usar para BR; reglas de negocio; rules-traceability.

Skill movido desde `requirements-engineering` (antes `af-business-rules-modeler`, G2). Capacidades originales preservadas: `af-business-rule-extractor`. Glosario y modelo de información pasaron a `biz-glossary-curator` y `biz-information-model-designer`.

No fusionar conceptos diferentes en una misma afirmación. Para cada salida declarar `sources`, `related`, `status` y control de cambios. Marcar como pregunta abierta, con responsable, todo lo que las fuentes no respalden.
