# Ejemplo de biz-rules-modeler

Entrada: Glosario TRM con gate G3 aprobado, BCP/BO/BCAP con sus gates aprobados y fuentes funcionales autorizadas (visión, procesos, políticas, User Stories, decisiones registradas).
Salida esperada: BR; `business/rules/BR-NNN.md` (uno por regla) más `business/rules/CTLG-BR.md` (CTLG); matriz de trazabilidad de reglas como sección de cada BR.
Bloqueo de ejemplo: afirmación sin fuente => registrar pregunta abierta con responsable y marcar CONDITIONAL o NOT_READY; no inventar contenido.
