# Guía técnica — biz-information-model-designer

Objetivo: Crear y mantener el modelo de información conceptual de negocio (conceptos, relaciones, cardinalidades, reglas y estados) previo a cualquier modelo lógico o físico. Usar para IMD; modelo conceptual; ER de negocio.

Fuente conservada: capacidad original `af-conceptual-model-designer` (script `check_model.py` incluido). Entrada natural de `ddd-domain-design` y `data-modeling-database-design`.

No fusionar conceptos diferentes en una misma afirmación. Para cada salida declarar `sources`, `related`, `status` y control de cambios. Marcar como pregunta abierta, con responsable, todo lo que las fuentes no respalden.
