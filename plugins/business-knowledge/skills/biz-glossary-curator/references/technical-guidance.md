# Guía técnica — biz-glossary-curator

Objetivo: Extraer y documentar conceptos, términos y siglas de negocio en un glosario TRM indexado alfabéticamente, con sinónimos, definición y fuentes con nivel. Usar para TRM; glosario; siglas; definir término.

Fuente conservada: capacidad original `af-business-glossary-curator`. El tipo OKF del término es `TRM` (STD-OKF-001 v1.9.0-stable); el índice es el catálogo `CTLG-TRM.md` (tipo `CTLG`). No se genera `index.md`.

No fusionar conceptos diferentes en una misma afirmación. Para cada salida declarar `sources`, `related`, `status` y control de cambios. Marcar como pregunta abierta, con responsable, todo lo que las fuentes no respalden.
