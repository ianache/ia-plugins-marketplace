# COMSATEL Infrastructure Plugin v1.4.0

Seven Skills: one orchestrator (user entry point) and six specialists (dispatched only by the orchestrator). Self-contained assets, templates, scripts, resources, examples. Modes greenfield, brownfield, evolution. Corporate OKF draft standard is not a stable approval.

Entry points: `/infra-architecture-design:infrastructure-plan` or the `infrastructure-orchestrator` skill.

Plan engine CLI: `python skills/infrastructure-orchestrator/scripts/workflow.py --help`.

Run `python -m unittest discover -s tests -v` to verify.
