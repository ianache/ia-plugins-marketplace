# Contrato local de uow-agent-execution-planner

Inputs: autorización del orquestador verificada por el runtime y los documentos que consume (ver SKILL.md). Outputs: Markdown OKF con `type: UAP`, `gate_proposal` de `AGENT_PLAN_GATE` y evidencia. Un resultado válido no aprueba el gate: lo decide el orquestador.
