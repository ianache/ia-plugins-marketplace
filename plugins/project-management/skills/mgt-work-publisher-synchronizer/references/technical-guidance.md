# Guía técnica — mgt-work-publisher-synchronizer

Objetivo: Publicar y sincronizar en GitLab el trabajo planificado (issues, labels, milestones, tablero) y registrar el linaje plan-issue. Usar para publicación GitLab; sync; publication-manifest.

Capacidades base: `gitlab-work-publisher` (scripts y contrato de publicación) y `report-userstory-testcase`.

Los skills externos citados (`gsd-*`, `gitlab-work-publisher`, `report-userstory-testcase`, `gitlab-ai-kpi-semanal`, `informe-mensual-horas-proyecto`, `development-scope-pack-builder`) se invocan como herramientas y no se copian ni se modifican aquí. Para cada salida declarar `sources`, `related`, `status` y control de cambios; marcar como pregunta abierta, con responsable, todo lo que las fuentes no respalden.
