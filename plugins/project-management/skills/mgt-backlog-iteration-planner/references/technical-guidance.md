# Guía técnica — mgt-backlog-iteration-planner

Objetivo: Priorizar el backlog y planificar iteraciones (alcance comprometido, dependencias, capacidad y Definition of Ready). Usar para SSP; plan de iteración; sprint; backlog.

Capacidades base: `gsd-plan-phase`, `gsd-review-backlog`, `gsd-discuss-phase` y `af-user-story-refiner`.

Estimación: `references/estimation-practice.md` (práctica v3), `scripts/estimate.py` y `assets/estimation-coefficients.json` (coeficientes con su estado de aprobación). Para el QA se leen los `TC` del pack `qa-design` (`execution: manual|automated`).

Los skills externos citados (`gsd-*`, `gitlab-work-publisher`, `report-userstory-testcase`, `gitlab-ai-kpi-semanal`, `informe-mensual-horas-proyecto`, `development-scope-pack-builder`) se invocan como herramientas y no se copian ni se modifican aquí. Para cada salida declarar `sources`, `related`, `status` y control de cambios; marcar como pregunta abierta, con responsable, todo lo que las fuentes no respalden.
