# Ejemplo de mgt-backlog-iteration-planner

Entrada: `PCH` y `RMP` con gate G1 aprobado; User Stories y paquetes de alcance (`DSP`) de `requirements-engineering`; capacidad y compromisos entregados por una persona.
Salida esperada: SSP. `management/sprints/SSP-NNN-<slug>.md`, un archivo por iteración.
Bloqueo de ejemplo: fecha, costo o capacidad sin fuente => registrar pregunta abierta con responsable y marcar CONDITIONAL o NOT_READY; no inventar el dato.
