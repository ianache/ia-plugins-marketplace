# Ejemplo de mgt-progress-reporting-analyst

Entrada: Plan e iteraciones (`SSP`), riesgos y cambios (`RSK`, `CHG`) con G4 aprobado, y datos reales de GitLab (issues, milestones, timelogs) del periodo.
Salida esperada: STR. `management/status-reports/STR-NNN-<periodo>.md`, uno por periodo.
Bloqueo de ejemplo: fecha, costo o capacidad sin fuente => registrar pregunta abierta con responsable y marcar CONDITIONAL o NOT_READY; no inventar el dato.
