Capacidades base: `gsd-audit-milestone`, `gsd-complete-milestone`, `gsd-milestone-summary`, `gsd-ship`.

Para cada salida declarar `sources`, `related`, `status` y control de cambios; marcar como pregunta abierta, con responsable, todo lo que las fuentes no respalden.
