# Ejemplo de mgt-release-closure-auditor

Entrada: Todos los entregables de G1 a G5, la decisión de calidad (`QDC`) del pack de QA cuando exista, y el estado real de issues, cambios y riesgos.
Salida esperada: CLS. `management/closure/CLS-NNN-<slug>.md`.
Bloqueo de ejemplo: fecha, costo o capacidad sin fuente => registrar pregunta abierta con responsable y marcar CONDITIONAL o NOT_READY; no inventar el dato.
