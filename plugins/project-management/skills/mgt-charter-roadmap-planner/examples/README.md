# Ejemplo de mgt-charter-roadmap-planner

Entrada: Alcance del run (G0 aprobado) y, si existen, la línea base de negocio (`BCP`, `BO`, `BCAP` de `business-knowledge`), el contexto de requisitos (RCP, paquetes de alcance `DSP`) y las decisiones de arquitectura (ASR, ADR).
Salida esperada: PCH; RMP. `management/charters/PCH-NNN-<slug>.md` y `management/roadmaps/RMP-NNN-<slug>.md`.
Bloqueo de ejemplo: fecha, costo o capacidad sin fuente => registrar pregunta abierta con responsable y marcar CONDITIONAL o NOT_READY; no inventar el dato.
