# Ejemplo de ejecución de `web-application-reconstruction-analyzer`

1. Confirmar `run_id`, escenario, fuentes y gate anterior.
2. Activar el skill desde Claude Code con fuentes versionadas.
3. Generar `as-is/application-inventory.md` con decisiones trazables.
4. Ejecutar `python skills/web-application-reconstruction-analyzer/scripts/validate.py <archivo-md>` para el entregable Markdown correspondiente.
5. Registrar evidencia y solicitar evaluación humana de **G1**.

Este ejemplo no representa una aprobación ni una ejecución real del agente.
