# G6 — checklist de revisión

- [ ] Contrato de entrada satisfecho o gaps declarados.
- [ ] Evidencia y fuentes trazables; no se presentan hipótesis como hechos.
- [ ] Resultado cubre: Opportunity brief, concepto seleccionado, hipótesis, límites, evidencia, riesgos y contrato de handoff.
- [ ] Alternativas, trade-offs, restricciones y riesgos documentados.
- [ ] Documento conceptual cumple STD-OKF-001 v0.1.0-stable cuando corresponda.
- [ ] Outcome técnico (`READY|CONDITIONAL|NOT_READY`) registrado.
- [ ] Aprobación humana explícita, no inferida del outcome.
